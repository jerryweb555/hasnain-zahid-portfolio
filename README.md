# Hasnain Zahid — Premium Personal Brand & Professional Portfolio

A world-class, responsive personal portfolio website engineered for **Hasnain Zahid**, positioning him as a **Customer Support Specialist | Sales & Client Communication Professional | Digital Marketing Freelancer | AI Enthusiast**.

---

## 🌟 Key Features & Tech Highlights

- **Frontend Core**: React 18, TypeScript, Tailwind CSS, HTML5, CSS3.
- **3D & Immersive Design**: Interactive Three.js 360-degree rotational hero visual featuring an illuminated faceted core, orbital rings, orbiting data nodes, ambient particle field, and mouse/touch gyro tracking.
- **Animations**: GSAP entrance timeline, micro-interactions, smooth scrolling, and reduced-motion compliance.
- **Design System**: Luxurious dark palette (`#07090e`, obsidian, glowing cyan and liquid silver), Figma-inspired typography (`Outfit`, `Plus Jakarta Sans`, and `JetBrains Mono`), and glassmorphism.
- **Authentic Credentials Integration**: Direct inclusion of original PDF certificates and Google Cloud badge with interactive modal viewer, credential ID copier, and direct downloads.
- **100% Truthful Data**: Strictly zero fabricated clients, revenues, or qualifications.

## 🚀 How to Run Locally

### Development Mode:
```powershell
npm.cmd run dev
```
Runs Vite development server at `http://localhost:3000`.

### Production Build:
```powershell
npm.cmd run build
```
Type-checks TypeScript and compiles an optimized production bundle into `/dist`.

### Preview Production Build:
```powershell
npm.cmd run preview -- --port 3000
```
Serves the production build locally at `http://localhost:3000`.
